# 同舟行跨境阶段 4：报表、预警、安全与上线实施计划

## 范围与口径

- 所有业务日期按 `America/Toronto` 自然日计算，筛选结束日期包含当天；数据库继续保存 UTC 时间。
- 销量与收入只统计极风确认已发货的普通包裹；补发数量单独统计，不计收入，避免重复计算销售额。
- SKU 报表以订单行保存的实际成交价和 SKU 快照为准；店铺报表按订单所属店铺聚合。
- 资金报表分别展示余额充值/扣减、订单余额消费/退款、已确认线下付款、待收款，不把加拿大元物流费混入人民币应收。
- 库存天数采用最近 7 个多伦多自然日的普通发货日均数量：`当前可售库存 ÷ 7 日发货量 × 7`。无销量时显示“暂无消耗基线”，不制造虚假预警。
- 可售天数 `<= 30` 为紧急、`> 30 且 <= 40` 为预警；同一 SKU 同一多伦多自然日只发一次系统/飞书通知。
- 本阶段不包含 AI 选品、行业资讯、广告费、平台佣金、线上充值、TEMU API 或正式补货审批单。

## Phase 4 Definition of Done

- 管理员能按多伦多自然日查看可信的 SKU、店铺、补发与人民币资金报表。
- 系统能按 7 日真实出库量计算 40/30 天库存预警，并在系统和飞书中每日幂等通知。
- 页面、日志、通知与报表不泄露消费者隐私或第三方凭证；运营健康状态可见且可行动。
- 备份恢复、部署、回滚、监控与凭证联调均有可执行手册；全部自动化检查通过。
