# 同舟行跨境交付路线图

本路线图将已批准的平台规格拆成四个可独立验收的实施计划。每一阶段必须通过测试和用户验收后，才进入下一阶段。

## 阶段 1：平台基础、客户店铺、商品与货盘库存

详细计划：`2026-08-12-tongzhouxing-foundation-catalog-inventory.md`

交付结果：带“同舟行跨境”品牌的可登录 Web 系统；超级管理员可以管理客户、店铺、SKU、默认价、客户价、SKU 别名和货盘库存；客户只能查看自己的价格和可售库存；所有库存调整有流水和审计。管理员和客户页面同时达到已批准 UI 简报规定的生产级高保真、WCAG 2.2 AA 和移动端适配标准。

## 阶段 2：TEMU Excel、订单与结算

阶段 1 通过后编写详细实施计划。

交付结果：客户选择店铺并上传 TEMU 原始 Excel；系统预览成功、重复和错误订单；提交时锁库存；余额充足自动扣款；余额不足支持 2 小时、申报付款后 12 小时的线下核款流程；取消、退款和超时释放库存均有流水。

## 阶段 3：极风履约、补发与飞书

阶段 2 通过后编写详细实施计划。开始前必须取得极风正式凭证、仓库和加拿大邮政渠道标识、补发接口说明，以及飞书应用和文档权限。

交付结果：已付款订单幂等推送极风；同步待发货、已发货、物流和费用；支持取消与补发；极风发货后正式扣库存；数据库数据在 1 分钟内同步飞书货盘，每晚全量校验；异常推送内部飞书群。

## 阶段 4：报表、预警、安全与上线

阶段 3 通过后编写详细实施计划。

交付结果：渥太华自然日的 SKU、店铺、补发和资金报表；7 日消耗与 40/30 天库存预警；隐私脱敏、审计检查、备份恢复演练、负载与并发验证、生产监控和部署手册。

## 阶段门禁

- 每阶段均以自动化测试、构建成功和真实浏览器验收为完成条件。
- 每阶段新增页面均必须遵守 `PRODUCT.md`、`DESIGN.md` 和 UI 设计简报；功能完成但视觉、响应式或无障碍未通过不算交付。
- 规格变化先修改设计规格，再修改当前阶段计划。
- 下一阶段不得绕过上一阶段提供的领域接口直接修改库存、余额或订单状态。
- 线上支付、TEMU API、正式补货审批、广告费和平台佣金不属于四阶段第一版交付。
