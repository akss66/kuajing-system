# 同舟行 UI V2

发布日期：2026-08-13

## 商家中心壳层与导航

- 管理后台与客户中心统一采用全宽顶部栏、分组侧边导航和一致的页面标题层级。
- 桌面端提供固定宽度工作区导航；移动端改为可关闭的导航抽屉，并保留清晰、唯一的当前页面状态。
- 通知、账号菜单、面包屑和主内容区域使用同一套响应式壳层规则。

## 账号、客户与店铺

- 账号管理重组为摘要、筛选、列表和按需编辑流程，降低密集表格中的操作干扰。
- 客户与店铺页面采用概览、详情分区和按需抽屉编辑，客户资料、登录账号、店铺、订单补发与资金信息更容易定位。
- 行级编辑表单不再常驻列表，查看与修改操作保持分离。

## 管理与客户仪表盘

- 管理仪表盘围绕今日经营、待办预警、趋势与快捷处理重新组织。
- 客户首页围绕未完成事项、快捷拿货、店铺摘要与资金摘要重新组织。
- 两类用户共享一致的信息层级，同时保留各自所需的导航与业务入口。

## 领域工作区

- 商品与 SKU、货盘库存、订单、补发、收款余额和统一结算使用一致的搜索、筛选、指标和内容面板结构。
- 客户货盘选品、TEMU 订单上传、多店铺批量拿货、我的订单与付款流程采用面向任务的步骤和反馈层级。
- 系统通知、外部集成、系统健康与审计日志纳入统一的系统管理工作区。

## 响应式与无障碍

- 关键页面覆盖桌面与 430px、390px、360px 移动视口，避免页面级横向溢出。
- 关键交互目标至少 44px，并补充移动导航焦点恢复、明确的当前页语义和键盘可用性。
- 颜色对比、标题结构、表单标签与状态反馈按无障碍要求校正。

## 兼容性边界

本次变更只调整界面呈现、信息架构与交互组织。业务状态机、权限规则、既有路由、审计行为及客户数据隔离均保持不变。
