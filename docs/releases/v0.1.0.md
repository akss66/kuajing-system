# 同舟行跨境 v0.1.0

发布日期：待正式凭证联调和生产环境批准后确定。

## 本版交付

- 数据库成为货盘库存唯一事实来源，库存调整、锁定、释放和发货扣减均可追溯。
- 客户按店铺上传 TEMU 原始 Excel 或选择系统 SKU 提交拿货单；实际成交价按订单行保存。
- 余额足够自动扣款进入待发货；余额不足可申报线下微信付款，由超级管理员核款。
- 极风订单幂等推送、轮询/Webhook、异常重试、取消、补发、加拿大邮政运单和加拿大元物流费已接入。
- 飞书货盘自动同步，极风异常、补发与 40/30 天库存覆盖预警同时进入系统和内部飞书群。
- 管理员可按多伦多自然日查看 SKU、店铺、补发和人民币资金报表。
- 交付审计、隐私脱敏、健康检查、安全响应头、备份恢复脚本和生产运行手册。

## 已确认延期

- TEMU API 直连；首版继续使用后台导出的原始 Excel。
- 正式补货审批单；首版由管理员人工调整库存补货并填写原因。
- AI 货品筛选、行业资讯。
- 广告费和平台佣金核算。
- 线上充值/支付；首版使用余额管理和线下微信付款。

## 正式上线前外部条件

- 极风正式域名、client id/secret、access/refresh token、user id、加拿大仓库编号、加拿大邮政渠道 ID。
- 极风补发仍按独立 ERP 单号调用订单创建接口；需用正式账号确认字段和回调契约。
- 飞书企业自建应用 app id/secret、货盘知识库协作者权限、电子表格权限和内部机器人群。
- 正式 HTTPS 域名、PostgreSQL、Web/Worker 进程托管、监控和加密备份存储。

## 已知安全说明

- `exceljs` 间接依赖已强制升级到修复后的 `uuid 11.1.1`，并通过 TEMU Excel 解析测试。
- `npm audit` 仍报告 4 个来自 `drizzle-kit` 旧开发打包链的中等级开发服务器告警；它们不用于 Web/Worker 处理业务请求。生产镜像/主机不应暴露任何开发服务器，升级 `drizzle-kit` 前须等待上游提供不破坏迁移兼容性的版本。
